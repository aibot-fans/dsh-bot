# 使用说明

Pod 装好以后（见 [README](../README.md#安装)），在 dsh web 侧栏里点「DeepSeek Pod」打开。这一页按界面从左到右讲怎么用。

## 界面布局

- 左侧栏顶部是搜索、新建（和主管开一段新对话）和临时对话，收起按钮在最右边。
- 下面依次是置顶（主管固定在第一个）、你建的分组、Bot 和群聊。新出现的排在前面，拖动可以调整顺序；各默认显示 5 个，其余点「更多」。底部是设置。
- 中间是对话。bot 详情、群聊详情和浏览器从右侧滑出，换对话或按 Esc 就关上。没有顶部导航。

## 侧栏

- 每一行悬停时有「…」（右键也行）：置顶、改名、移到分组、归档、删除。
- 也可以直接拖：拖进置顶就置顶，拖进分组就移进分组。
- 有新消息的显示红色未读数。
- 归档的不占侧栏，在设置的「归档」页里；删除的 bot 和群聊进设置的「回收站」，30 天内可以恢复。

## 对话

- 对话顶部左边是 bot（或成员拼成的群图标），点开看详情；点群名直接改名。
- 右边是「对话记录」（和这个 bot 之前的每段对话，点开接着聊，也能删）、「新对话」和这个对话今天的用量（全部用量在设置里）。
  - 「新对话」只有单聊有：开一段新的，新对话里 bot 能翻之前的对话；临时对话不能。
- 侧栏里点 bot，打开和它最近的那段对话。往上翻历史时右下角有「回到最新」，有新消息时显示条数。
- bot 回答时下面有一块执行进度，可以随时停止：
  - 正在做什么（跑命令时下面一行小字是原始命令和这一步跑了多久）、已经多久、第几步；bot 列了计划的话，显示计划做到哪。
  - 正在想时显示它想的最后一句，想完了写“想了 N 秒”；想的内容不保存。点“看每一步”展开每一步用了多久、成没成。
  - 一步跑了太久、连着出错、连着做同一步、计划很久没动时，下面出一行黄色提示，可以点“让它汇报”或“停止”。
  - 回答进行中也可以直接说话补充或纠正，它下一步就会看到（群里要 @ 它）。
  - 用了好几步或者超过一分钟的回答，跑完在回复下面留一行：用时、几步、想了多久，点开看计划和每一步（只有一句话，不存命令输出）。
- 输入框可以直接粘贴或拖入图片和文件。
  - 文件能在页面里预览：Markdown、表格、图片、PDF、音视频、JSON、HTML 和文本；Office 文件给下载，太大的文字文件只显示开头。
  - 上传的 PDF、Word、Excel、PPT 会自动转一份文字版（附件旁边点「文字版」看），bot 直接读文字版。转不了的（老版 .xls、.ppt，加了密码的）在附件下面写明原因。
- 鼠标移到消息上浮出复制、引用、重新回答、赞、踩。

## 群聊

- 一个任务一个群聊，群名是不超过 8 个字的主题词。任务卡原地刷新（阶段、分段进度条、验收项、执行进度、花费），完成后变成交付卡。
- 输入 @ 点名成员，@ 到的名字标成蓝色。
- 没点名的话，Pod 按成员的分工交给对口的成员来接；引用了谁的消息就交给谁，只有一个成员的群直接交给它。
  - 主管在群里只管分派和组织：新建 bot、拉人进群、要几个成员配合的大任务、Pod 本身怎么用。具体的活交给成员，“能做就自己做”只在你和主管的单聊里。
  - 任务群和正式团队的群里，没点名时由组长接。
- 成员做完自己那份，以自己的名义在群里说做完了什么、文件在哪；组长验收通过或打回记成一行状态。
- 群里的 bot 也会互相点名：点名是它这一轮的最后一步，被点名的直接在群里回答，不会再 @ 回去；bot 文字里顺带提到的 @ 显示成淡色。
- 一段回复里先放 bot 说的话，它做的页面、派的任务卡、开的网页这些卡片放在下面。
- 消息里的 @名字 带图标，点了能看详情。
- 主管拉了群，提示里的群名可以直接点进去。

## bot 的图标和颜色

- 每个 bot 有自己的鲸鱼图标：30 种角色（领导、程序员、写作、翻译、设计师、运维……），看不出定位的用「万能助手」。按名字和角色自动配，尽量不重样。
- 小头像是头部特写，详情页和选图标时是全身图；提到 bot 的地方都显示图标和名字。
- 名字也有自己的颜色：每个 bot 随机配一种，侧栏、群聊、消息里都用这个颜色。浅色和深色主题各画一套：色相是 bot 自己的，深色主题下更亮，和背景的对比度都在 4.5 以上，看得清也不刺眼。新 bot 配色时会避开和已有 bot 画出来太像的颜色。
  - 想换的话，在 bot 详情里点名字前的圆点：第一个是现在的颜色，后面是一批随机颜色，点一个就换；不满意点「换一批」。
- 群聊的图标是成员的小图标拼起来的，每一格垫着这个成员的颜色，拉人、踢人以后马上跟着变。不超过 4 个成员全放上，主管排在最后；超过 4 个放前 3 个，第 4 格写「+N」。

## bot 详情和群聊详情

- bot 详情能改全部设定：名字、角色、头像（换小图标或上传图片）、能力标签、角色卡、人设、模型、思考强度、工具档案、临时。
- 也能看资料库、自动化、浏览器、页面，以及记忆、技能、成长记录、历史版本。
- 群聊详情有成员（一格一格带完整名字，能一次加几个）、群约定、群记忆、消息提醒、资料库、自动化、任务、页面和浏览器（群里的 bot 开的网页，也能在这里开）。
- 在群聊详情或消息里点成员，打开成员卡片：可以单聊、在群里 @ 它、移出，也能返回群聊详情。从成员卡片进「完整资料」后能返回成员卡片。

## 页面

- bot 做好页面后，对话里出现页面卡片。点开后中间换成页面查看器：
  - 右边「修改」直接写想怎么改，只交给做这个页面的 bot，改好后页面自动刷新到新的一版。
  - 「版本」里能预览旧版、把旧版恢复成新的一版。
  - 顶部能改标题、导出 PDF、PNG 长图或 HTML 文件。
- bot 详情和群聊详情里的「页面」页签列出它做的（这个群里做的）页面。「查看全部」打开页面库：按 bot 和群聊分组（当前对话那组在前），能按种类筛、按标题搜、置顶、改名、删除（进回收站，30 天内能恢复）。
- 全局搜索也能搜到页面。新建定时例程时可以选一个页面，例程每次运行都更新它。

## 新建

- 新建 bot 只要名字和一句话职责，也可以交给主管来建；也可以直接用「设计师」预设（做页面的，常驻）。
- 新建群聊点选成员就行，群名可以不填。
- 临时对话不进列表、不写记忆，离开就删。

## 共用浏览器

- 所有 bot 共用一个无头 Chrome 和一份登录状态，按标签页分工。
- bot 打开网页时，对话里出现浏览器卡片，点开从右侧看实时画面，可以接管和交还。要登录的网站，接管后你自己登录，交还给 bot 接着做。
- 写操作（提交、发送、删除、购买、确认、POST 表单）要你批准，审批卡带截图和表单内容。bot 永远不填密码、验证码、银行卡号；你接管时填的这些，bot 读页面和审批卡里也只看到「已填」，看不到值。
- 默认不能访问本机和局域网地址；确实要访问的，在设置的「浏览器」页加进白名单。

## X 数据和监控

- 第一次启动自动开通 aibot，不用注册登录。bot 能查 X（推特）上的用户、推文、搜索和趋势；每天有免费次数（读一次算一次），早上 8 点（北京时间）恢复。
- 能监控账号（免费 40 个，监控不扣次数），新动态实时发进「X 监控」群聊并发通知。想盯谁，在「X 监控」群里跟 X 情报员说“监控 @账号名”。
- X 工具装给「X 情报员」、主管、标签里提到 X 或推特的 bot，以及「X 监控」群里的会话。
- 设置「通用」页里能看今天还剩几次、监控了几个账号，也能整个关掉。

## 设置

- 设置分八页：
  - 通用：含 X 数据和监控（开关、今日剩余次数、监控数；aibot 开放绑定后才有「绑定账号」）。
  - 用量：按时间、成员、对话看用量；最下面是 aibot 今天还剩几次、几点恢复。
  - 自动化：所有自动化一个列表。点 bot 的名字可以换一个来做。群里的成员也能给自己建定时例程，记在自己名下、发到这个群。
    - 时间可以是每天、每周几、每隔几分钟或几小时、cron，也可以只跑一次（到点跑完自动删掉）。
    - 跟 bot 说“把早报改到 9 点”“先暂停盯价格”“结果改发到量化群”，它直接改好，并告诉你下次什么时候跑。
    - bot 不能直接读写 Pod 的数据库和 dsh 目录（命令和文件工具都会被拦下），只能通过 Pod 的工具改。
  - 模型、浏览器、归档、回收站、高级。
- 第一次打开有引导（会说 X 数据和监控开通了没有、每天免费几次）；设置里可以「再看一遍」。

## 快捷指令和反馈

- 输入框里以 `/` 开头是快捷指令：`/任务` `/评审` `/建群` `/邀请` `/停止` `/总结`。
- bot 的回复可以点赞、点踩（附原因）、重新回答。这些反馈会用来调整 bot 的人设和做法；调得不好，可以在 bot 详情的「成长记录」里撤回，「历史版本」里能回到任何一版设定。
