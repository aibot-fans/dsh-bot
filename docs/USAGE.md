# 使用说明

dsh-bot 装好以后（见 [README](../README.md#安装)），在 dsh web 侧栏里点「dsh-bot」打开。这一页按界面从左到右讲怎么用。

## 界面布局

- 左侧栏顶部是搜索、新建（和主管开一段新对话）和临时对话，收起按钮在最右边。
- 下面依次是置顶（主管固定在第一个）、你建的分组、Bot 和群聊。新出现的排在前面，拖动可以调整顺序；各默认显示 5 个，其余点「更多」。底部是设置。
- 中间是对话。bot 详情、群聊详情和浏览器从右侧滑出，换对话或按 Esc 就关上。没有顶部导航。

## 在手机上用

- 窄屏（手机、窄窗口）上一次只显示一页：先是列表，每一行有名字、最近一条消息、时间和未读数；点进去是对话，左上角返回列表。
- 详情、设置、搜索、页面和浏览器都占满整屏，左上角返回。手机自带的返回（安卓返回键、iPhone 从左边缘右滑）也是一层一层往回退，退到列表为止。
- 菜单从屏幕底部升起，点空白处或「取消」关上。
- 长按一条消息弹出操作：复制、选择文字（打开原文，自己选一段）、引用回复，bot 的回答还有重新回答、赞和踩，最后是置顶和查看过程。长按列表里的一行是置顶、改名、移到分组这些。
- 触屏上不能拖动排序，用长按菜单里的置顶和移到分组。
- 弹出键盘时输入框跟着上来，点输入框不会把页面放大。

## 侧栏

- 每一行右键（手机上长按）弹出菜单：置顶、改名、移到分组、归档、删除。
- 也可以直接拖：拖进置顶就置顶，拖进分组就移进分组。
- 有新消息的显示红色未读数。
- 归档的不占侧栏，在设置的「归档」页里；删除的 bot 和群聊进设置的「回收站」，30 天内可以恢复。

## 对话

- 对话顶部左边是 bot（或成员拼成的群图标），点开看详情；点群名直接改名。
- 右边是「对话记录」（和这个 bot 之前的每段对话，点开接着聊，也能删）、「新对话」和这个对话今天的用量（全部用量在设置里）。
  - 单聊的「新对话」开一段新的，新对话里 bot 能翻之前的对话；临时对话不能开。
  - 群聊没有「对话记录」，「新对话」还在这个群里：时间线上加一条分隔线，群里的 bot 从这里重新开始，不再带着之前的群聊，你提到之前的事时它们自己去翻；之前的聊天还在上面。任务群没有「新对话」。
- 侧栏里点 bot，打开和它最近的那段对话。往上翻历史时底部中间有圆形的「回到最新」，有新消息时角上显示条数；你发出消息时会自动回到最新。
- 你的消息下面写着发出的时间，同一分钟连着发的几条只在最后一条下面写。
- 发出去马上有回应：群里没点名时先显示「正在找合适的成员来接」，挑好了是「正在接收消息」；bot 那段会话空闲太久或上下文太长要换一段时，显示「正在整理之前的对话」（写交接笔记，要十几秒）。bot 开始回答后换成下面的执行进度。
- bot 回答时下面有一块执行进度，可以随时停止：
  - 正在做什么（跑命令时下面一行小字是原始命令和这一步跑了多久）、已经多久、第几步；bot 在这一轮列了计划的话，显示计划做到哪（上一轮没做完的计划不带过来）。
  - 正在想时显示它想的最后一句，想完了写“想了 N 秒”；想的内容不保存。点“看每一步”展开每一步用了多久、成没成。
  - 一步跑了太久、连着出错、连着做同一步、计划很久没动时，下面出一行黄色提示，可以点“让它汇报”或“停止”。
  - 回答进行中也可以直接说话补充或纠正，它下一步就会看到（群里要 @ 它）。
  - 用了好几步或者超过一分钟的回答，跑完在回复下面留一行：用时、几步、想了多久，点开看计划和每一步（只有一句话，不存命令输出）。
- 输入框可以直接粘贴或拖入图片和文件。
  - 文件能在页面里预览：Markdown、表格、图片、PDF、音视频、JSON、HTML 和文本；Office 文件给下载，太大的文字文件只显示开头。
  - 上传的 PDF、Word、Excel、PPT 会自动转一份文字版（附件旁边点「文字版」看），bot 直接读文字版。转不了的（老版 .xls、.ppt，加了密码的）在附件下面写明原因。
- 鼠标移到消息上浮出复制、引用、重新回答、赞、踩。
- 消息的「…」里可以置顶。有置顶的消息时，对话顶部多一条置顶条，显示最新的一条，点它跳到那条消息；右边展开是全部置顶消息，能跳过去、能取消置顶。bot 开新会话时（比如群聊开了新对话）会带上这个对话里置顶的消息。

## 输入框

- Enter 发送，Shift+Enter 换行，Cmd/Ctrl+Enter 在哪都是发送。中文输入法组字时按 Enter 只上屏，不会发出去。
- 常用的 Markdown 边打边变成格式，刚变完按退格能变回原来的字：
  - 行首打 `- ` 或 `1. ` 开始列表：Enter 接下一项，在空的一项上再按 Enter 结束列表；Tab 缩成子项，Shift+Tab 退回。
  - 行首打 `> ` 是引用，`# ` 到 `### ` 是标题。
  - 行首打 ```` ``` ```` 加空格（或者单独一行 ```` ``` ```` 后按 Enter）是代码块，里面 Enter 换行、Tab 缩进；连按三次 Enter 或在末尾按 ↓ 出来。
  - `**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` ``。星号两边都紧挨字母数字时不算（`2*3*4` 原样），单个 `~` 也不算（`3~5 天`）。
- 快捷键：Cmd/Ctrl+B 粗体、I 斜体、E 行内代码、Shift+X 删除线、Shift+7 有序列表、Shift+8 无序列表、Shift+9 引用、Alt+C 代码块。
- 粘贴：Markdown 文字按格式排好，网页上复制的保留列表、粗体这些，VS Code 里复制的多行代码变成代码块；Cmd/Ctrl+Shift+V 粘成纯文字。图片和文件变成附件。
- 发出去的是 Markdown，时间线上按同样的规则显示（嵌套列表、删除线、引用里的列表都行）。没发的草稿也按 Markdown 存着，换个对话、关掉页面再回来还在。

## 群聊

- 一个任务一个群聊，群名是简短的主题词（最好不超过 12 个字，起好的名字不会被截断）。任务卡原地刷新（阶段、分段进度条、验收项、执行进度、花费），完成后变成交付卡。
- 输入 @ 点名成员，@ 到的名字标成蓝色。
- 没点名的话，dsh-bot 按成员的分工交给对口的成员来接；引用了谁的消息就交给谁，只有一个成员的群直接交给它。
  - 主管在群里只管分派和组织：新建 bot、拉人进群、要几个成员配合的大任务、dsh-bot 本身怎么用。具体的活交给成员，“能做就自己做”只在你和主管的单聊里。
  - 任务群和正式团队的群里，没点名时由组长接。
- 成员做完自己那份，以自己的名义在群里说做完了什么、文件在哪；组长验收通过或打回记成一行状态。
- 群里的 bot 也会互相点名：点名是它这一轮的最后一步，被点名的直接在群里回答，不会再 @ 回去；bot 文字里顺带提到的 @ 显示成淡色。
- 一段回复里先放 bot 说的话，它做的页面、派的任务卡、开的网页这些卡片放在下面。
- 消息里的 @名字 带图标，点了能看详情。
- 主管拉了群，提示里的群名可以直接点进去。

## bot 的图标和颜色

- 每个 bot 有自己的鲸鱼图标：30 种角色（领导、程序员、写作、翻译、设计师、运维……），看不出定位的用「万能助手」。按名字和角色自动配，尽量不重样。
- 小头像是头部特写，详情页和选图标时是全身图；提到 bot 的地方都显示图标和名字。
- 名字也有自己的颜色：每个 bot 随机配一种，侧栏、群聊、消息里都用这个颜色。浅色和深色主题各画一套：色相是 bot 自己的，深色主题下更亮，和背景的对比度都在 4.5 以上，看得清也不刺眼。新 bot 配色时会避开和已有 bot 画出来太像的颜色。
  - 想换的话，在 bot 详情里点名字前的圆点：第一个是现在的颜色，后面是一批随机颜色，点一个就换；不满意点「换一批」。
- 群聊的图标是成员的小图标拼起来的，每一格垫着这个成员的颜色，拉人、踢人以后马上跟着变。不超过 4 个成员全放上，主管排在最后；超过 4 个放前 3 个，第 4 格写「+N」。

## bot 详情和群聊详情

- bot 详情能改全部设定：名字、角色、头像（换小图标或上传图片）、能力标签、角色卡、人设、模型、思考强度、工具档案、临时。
- 也能看资料库、自动化、浏览器、页面，以及记忆、技能、成长记录、历史版本。
- 群聊详情有成员（一格一格带完整名字，能一次加几个）、群约定、群记忆、消息提醒、资料库、自动化、任务、页面和浏览器（群里的 bot 开的网页，也能在这里开）。
- 在群聊详情或消息里点成员，打开成员卡片：可以单聊、在群里 @ 它、移出，也能返回群聊详情。从成员卡片进「完整资料」后能返回成员卡片。

## 页面

- bot 做好页面后，对话里出现页面卡片，每存一版发一张。点开的是卡片上的那一版（后来又改过的，顶上标着在看第几版、最新第几版），中间换成页面查看器：
  - 右边「修改」直接写想怎么改，只交给做这个页面的 bot，改好后页面自动刷新到新的一版。
  - 「版本」里能预览旧版、把旧版恢复成新的一版。
  - 顶部能改标题、导出 PDF、PNG 长图或 HTML 文件。
- bot 详情和群聊详情里的「页面」页签列出它做的（这个群里做的）页面。「查看全部」打开页面库：按 bot 和群聊分组（当前对话那组在前），能按种类筛、按标题搜、置顶、改名、删除（进回收站，30 天内能恢复）。
- 全局搜索也能搜到页面。新建定时例程时可以选一个页面，例程每次运行都更新它。

## 新建

- 新建 bot 只要名字和一句话职责，也可以交给主管来建；也可以直接用「设计师」预设（做页面的，常驻）。
- 新建群聊点选成员就行，群名可以不填。
- 临时对话不进列表、不写记忆，离开就删。

## 共用浏览器

- 所有 bot 共用一个无头 Chrome 和一份登录状态，按标签页分工。
- bot 打开网页时，对话里出现浏览器卡片，点开从右侧看实时画面，可以接管和交还。要登录的网站，接管后你自己登录，交还给 bot 接着做：点「交还给它」，可以留一句话，例如「已登录」。bot 请你接管时，画面上方会提示。
- 单聊和群聊顶部都有「浏览器」按钮。浏览器上面只有一条工具栏，下面全是画面：左边点网页标题切换网页（列出所有开着的网页，这个对话、这个 bot 的排前面，别处的在「其他对话」下面，默认选最近用过的那个）；中间是前进后退、网址、谁在操作和「接管」「交还」，在状态上停一下能看到说明；右边的 + 在这个对话里开新网页，「更多」里是复制选中的文字、截图、动作记录和停止标签页。
- dsh web 重启后，你自己开着的网页在打开浏览器时按原网址恢复（bot 的标签页不恢复，它们要用时自己重开）。
- 浏览器右上角能「窗口内全屏」：盖住整个窗口，工具栏收成一行，画面按窗口放到最大，Esc 或再点一下退出。全不全屏会记住，下次打开浏览器还是那样（每台设备各记各的）。从群聊、bot 详情的浏览器页「放大看」进来的，左上角「返回」（或按 Esc）回到详情。
- 写操作（提交、发送、删除、购买、确认、POST 表单）要你批准，审批卡带截图和表单内容。bot 永远不填密码、验证码、银行卡号；你接管时填的这些，bot 读页面和审批卡里也只看到「已填」，看不到值。
- 默认不能访问本机和局域网地址；确实要访问的，在设置的「浏览器」页加进白名单。

## X 数据和监控

- 第一次启动自动开通 aibot，不用注册登录。bot 能查 X（推特）上的用户、推文、搜索和趋势；每天有免费次数（读一次算一次），早上 8 点（北京时间）恢复。
- 能监控账号（免费 40 个，监控不扣次数），新动态实时发进「X 监控」群聊并发通知。想盯谁，在「X 监控」群里跟 X 情报员说“监控 @账号名”。
  - 有监控时 dsh-bot 一直连着 aibot 的实时事件流（断线自动重连，连上后补上断线期间的），推文发出后一般几秒内就进群，不是定时去查。
- X 工具装给「X 情报员」、主管、标签里提到 X 或推特的 bot，以及「X 监控」群里的会话。
- 在 dsh-bot 的浏览器里登录 X 以后，bot 能用你的账号查推文、用户、时间线、搜索、关注列表、通知、书签和私信，也能发推、回复、引用、删推、点赞、转推、加书签、置顶、关注、拉黑、静音。bot 先列出接口（x_list_endpoints）、看录下的请求（x_get_operation），改了参数发出去（x_api_request），响应存在 dsh-bot 里，用 jq 挑要的部分（x_filter_response）。拿登录凭据、要密码或读邮箱手机号的接口不替 bot 调。
  - 加密聊天：在 dsh-bot 的浏览器里打开 https://x.com/i/chat 输一次密码以后，bot 能列出会话（x_chats）、读消息（x_chat）。
  - 发推能带图片、GIF 和视频：工作区里的文件，最多 4 个，每个可以写说明文字。大小和时长按 X 给这个账号的上限（太大的图片 X 会自己压缩），一个文件最多 1 GB。
  - 改东西的请求默认每次出审批卡：卡上有接口、正文、照原样要发的参数和每个附件的名字和大小，图片显示缩略图，点开能看大图、放视频。批准时 dsh-bot 再读一遍文件，提交以后改过的就不发。
  - 设成免审批时，只有发推、删推、点赞、转推、书签、置顶、关注、拉黑、静音直接做，别的写请求照样出审批卡；读过网页或 X 上内容的会话带文件发推，也先给你看一眼。
- 设置「通用」页里能看今天还剩几次、监控了几个账号，也能整个关掉。

## 设置

- 设置分八页：
  - 通用：含聊天区宽度（窄、宽、铺满，只存在这台设备上，手机上总是铺满）、X 数据和监控（开关、今日剩余次数、监控数；aibot 开放绑定后才有「绑定账号」）。
  - 用量：按时间、成员、对话看用量；最下面是 aibot 今天还剩几次、几点恢复。
  - 自动化：所有自动化一个列表。点 bot 的名字可以换一个来做。群里的成员也能给自己建定时例程，记在自己名下、发到这个群。
    - 时间可以是每天、每周几、每隔几分钟或几小时、cron，也可以只跑一次（到点跑完自动删掉）。
    - 跟 bot 说“把早报改到 9 点”“先暂停盯价格”“结果改发到量化群”，它直接改好，并告诉你下次什么时候跑。
    - bot 不能直接读写 dsh-bot 的数据库和 dsh 目录（命令和文件工具都会被拦下），只能通过 dsh-bot 的工具改。
  - 模型、浏览器、归档、回收站、高级。
- 第一次打开有引导（会说 X 数据和监控开通了没有、每天免费几次）；设置里可以「再看一遍」。

## 快捷指令和反馈

- 输入框里以 `/` 开头是快捷指令：`/任务` `/评审` `/建群` `/邀请` `/停止` `/总结`。
- bot 的回复可以点赞、点踩（附原因）、重新回答。这些反馈会用来调整 bot 的人设和做法；调得不好，可以在 bot 详情的「成长记录」里撤回，「历史版本」里能回到任何一版设定。
